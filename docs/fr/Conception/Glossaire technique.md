# Glossaire Technique

## Concepts
| Terme | Définition | Traçabilité |
|-------|------------|-------------|
|Langage de developpement| Langage informatique utilisé pour la réalisation du projet (Python, ...) | Utilisation de Python pour des raisons de simplicité et de compatibilité avec les outils d'IA et autres   |
|Framework web | Ensemble de bibliothèques et d’outils pour créer une application web.   | Pyramid (contrainte imposée par le client)  |
|Langage de template | Langage utilisé pour l'implémentation de modèles pour la création des pages web | TAL/METAL (contrainte imposée par le client)   |
|Framework | Ensemble de bibliothèques et d'outils utilisés dans le projet. | SolidJS, Bootstrap  (contraintes imposées)  |
|Depot git | Système de versionnage utilisé pour stocker le code du projet et les différentes oeuvres de la bibliothèque   | contrainte imposée par le client   |
|Base de données | Système qui stockes les données de l'application  | Pas utilisée puisque les documents sont stockés dans le dépôt Git   |
|Arborescence de fichiers | Organisation des fichiers sous forme d'arbre | Contrainte imposée par le client |
|Architecture logicielle orienté objet | Architecture logicielle se basant autour d'objets et concepts du monde réel | Contrainte imposée par le client |
|Modelisation UML (Unified Modeling Language) | Modélisation graphique pour la visualisation des concepts issus l'architecture orientée objet  | Utilisé pour décrire les concepts utilisés dans l'application (contrainte imposée par le client) |
|Design Pattern | Solution réutilisable face à un problème récurrent en informatique | Utilisés dans le projet lorsque l'occasion se présente   |
|Documentation | Ensemble de documents et commentaires permettant d'augmenter la compréhensibilité du projet et du code | Les différents fichiers de codes du projet sont commentés. La documentation globale du projet et de son architecture se trouve le répertoire `biblioteko/docs/fr` |
